# 习思想章节练习

按章节刷题的静态网页，适合部署到 GitHub Pages。

## 功能

- 8 个章节、204 道题：92 道单选题、112 道多选题。
- 单选题点击选项后立即显示本题答案与解析；多选题勾选后提交。
- 每题包含答题依据、选项辨析和记忆要点。
- 错题自动累计，按章节查看、重新练习、筛选待巩固或已掌握。
- 答题进度、错题及多选草稿保存在当前浏览器。
- 适配电脑和手机，支持章节筛选、题型筛选及随机练习。

## GitHub Pages 发布

1. 在 GitHub 创建一个公开仓库，例如 `xisixiang-quiz`。
2. 把本目录内的文件上传到仓库根目录的 `main` 分支，根目录须包含 `index.html`。
3. 打开仓库的 **Settings → Pages**。在 **Source** 选择 **Deploy from a branch**，分支选择 **main**，目录选择 **/(root)**，保存。
4. 在 Pages 设置页等待发布完成，使用 **Visit site** 打开的实际网址。

不需要安装前端依赖或配置构建命令。所有必要脚本和样式都在仓库内，资源使用相对路径，支持 GitHub Pages 项目子目录。

官方发布说明：https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## 验证

可选：安装 Node.js 后执行 `node tests.cjs`。测试覆盖 204 道题的参考答案、精确多选判题、作答前答案隐藏、解析显示、错题汇总与掌握标记、章节切换以及刷新恢复。使用 DOM 适配器验证界面逻辑，尚未进行真实手机微信测试。

## 题库与记录

题目及参考答案来自原有八份教材配套练习文档；解析补充答题依据、选项辨析、记忆要点和延伸阅读。保留原文参考答案，原题疑点在解析中说明。

每个设备和浏览器独立保存练习记录，尚无账号和云端同步。更换网址后，浏览器存储属于新域名，旧网站的记录不自动迁移。网络和微信的访问规则仍可能影响实际打开效果。
