## 使用

- 先选择再提交，提交前不显示本题答案。多选题须完整匹配答案。
- 每题提交后显示答案与考点解析，含选项辨析或记忆要点；支持重新作答。
- 每个专题支持顺序、乱序以及单选/多选筛选。乱序只改变题目顺序，不改变原选项字母。
- 错题自动进入错题库，可按专题、待巩固/已巩固筛选并进行乱序专项练习。答对标记已巩固，不自动移出错题库。
- 重做专题只清除本专题作答，保留全部错题和其他专题记录。
- 当前设备浏览器自动保存进度、本轮位置和选项草稿，支持JSON备份导出与合并导入。
- 知识点支持关键词查找、章节筛选和记住标记。思考题默认折叠，可先回忆再展开。
- 单文件HTML，无外部字体、CDN或接口依赖，适配电脑和手机。

## 资料与修订

主专题取自 https://maogai.szhopc.cn/ 的习思想课程第1—5、17章。七个补充来自用户提供的导论、第1—5、17章练习文档。知识点和思考题依据用户提供的《习近平新时代中国特色社会主义思想概论》（2023版）精简归纳，章节与教材原题已按扫描页核对。

修正明确错字、重复选项、缺失选项与明显错误答案，并在对应题目提交后的说明中保留修订信息。补充7多选第16题原件未给答案，已结合题意补全为ABCDE。少数语义交叉题保留来源答案并说明疑点。补充材料中的历史表述保留其语境。

学习记录保存在当前设备、当前浏览器，不会上传GitHub；换设备可用备份迁移。网站的题目和解析属于公开页面内容，答案保护是作答流程中的界面保护。
